🎓 Student Management System (C++)

📌 Overview

This project is a Student Management System developed in C++. It allows users to efficiently manage student records through a simple and user-friendly console interface. The system performs basic operations like adding, displaying, searching, and managing student data.

---

🚀 Features

- ➕ Add new student records
- 📋 Display all student details
- 🔍 Search student by ID or name
- ✏️ Update existing records
- ❌ Delete student records
- 💾 File handling for data storage (persistent data)

---

🛠️ Technologies Used

- C++
- File Handling (for storing student data)
- Object-Oriented Programming (OOP concepts)

---

📂 Project Structure

├── main.c++          # Main source code
├── StudentData.txt   # Data file for storing records
└── README.md         # Project documentation

---

▶️ How to Run

1. Clone the repository:
   git clone https://github.com/anmol3106/Student-Management-System.git
2. Navigate to the project folder:
   cd Student-Management-System
3. Compile the code:
   g++ main.c++ -o main
4. Run the program:
   ./main
